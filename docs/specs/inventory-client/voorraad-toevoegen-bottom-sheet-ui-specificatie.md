# UI-specificatie — Voorraad toevoegen

- Functionele specificatie: [voorraad-toevoegen-bottom-sheet-specificatie.md](./voorraad-toevoegen-bottom-sheet-specificatie.md)

De bottom sheet behoudt de bestaande compacte flow:

1. zoek concreet product;
2. toon gedeelde productweergavenaam en afbeelding;
3. vul geheel aantal fysieke verpakkingen in;
4. kies locatie;
5. kies optioneel THT;
6. bevestig.

De UI legt uit dat bijvoorbeeld `3` drie afzonderlijk aanpasbare fysieke verpakkingen toevoegt.
