# Acceptancecriteria

- Via de + (FAB) knop rechts onderaan wordt de AddConsumptionLog geopend.
- Er is een invoerveld op het modal die realtime de ingevoerde letters gebruikt om de naam van de consumptie op te zoeken.
- Onder het invoersveld worden suggesties laten zien op basis van de ingevoerde letters.
- Er is een invoerveld op het modal voor de hoeveelheid van het product.
- Rechts van de hoeveelheid is een dropdown menu waarmee de unit type gekozen kan worden.
- Met de Voeg toe knop op het modal wordt geprobeerd de data in de de consumptionlog tabel te zetten
